# Jogo-de-adivinhacao-em-Python
Jogo simples de adivinhação em Python: tente descobrir o número secreto entre 1 e 20 em até cinco tentativas, com dicas a cada palpite.
Este repositório contém um jogo de adivinhação desenvolvido em Python. O programa sorteia automaticamente um número secreto entre 1 e 20, e o jogador tem cinco tentativas para acertá-lo. A cada palpite, o jogo informa se o número inserido está acima ou abaixo do valor correto, fornecendo feedback imediato para ajudar o usuário a se aproximar da resposta.

O projeto é simples, mas demonstra conceitos fundamentais de programação, sendo ideal para iniciantes que desejam praticar lógica de programação, controle de fluxo e interação com o usuário via terminal.

# Recursos e conceitos abordados

Geração de números aleatórios utilizando a biblioteca random

Estruturas condicionais: if, elif, else

Estrutura de repetição com controle de tentativas (while)

Interação com o usuário através da entrada de dados (input)

Controle de fluxo básico e lógica de jogo
